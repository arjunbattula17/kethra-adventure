## Made in this repo (original, or generated in code)
Everything below is generated by code in this repository, so it carries no third-party licence.
Items marked *(AI-written code)* were produced with an AI coding assistant during development; see
docs/AI_AND_ASSET_LOG.md for what that means for the honor statement.
- The space sky (stars and galactic band): generated at runtime by `src/galaxy/spaceSky.ts`
  (seeded). It replaced `public/textures/space/starfield.jpg` on 2026-09-27.
- Every procedural canvas texture (ship walls, floors, screens, signage, decals, Kethra runes):
  generated at runtime by the `*Textures.ts` builders in `src/`.
- All sound and music: synthesized at runtime with the Web Audio API in
  `src/audio/AudioSystem.ts` (no audio files). The music beds are generative (chords plus plucks
  picked at random from one scale), so there is no recording to license. *(AI-written code)*
- Characters (the Aiveth, Harbormaster Varro, Dace): built from primitives in code,
  `src/characters/Figure.ts`, including the Aiveth vein texture. *(AI-written code)*
- Kethra set pieces: the Wickmoth and its stained-glass wing texture, the Cistern Heart, the
  lantern bloom, the shrine stele and the Rite glyphs, `src/planets/kethra/grove.ts`.
  *(AI-written code)*
- Vessek Anchorage: the hall layout (from the CC0 sci-fi kit above), its painted signs, the breaker
  board face, the ledger pages and the ring plate, `src/planets/vessek/VessekScene.ts`.
  *(AI-written code)*
- The ending's transmission rings and the title logo treatment (CSS). *(AI-written code)*
- The Wren's hull, in every space scene and as the Anchorage's moored ships: built in code,
  `src/galaxy/shipHull.ts` (2026-09-27). It replaced the CC BY "Colored Freighter" model.
- Kethra's colonnade, its resting moths and the crystal in the Cistern Heart's basin: built in code,
  `src/planets/kethra/dressing.ts` (2026-10-13). They replaced three CC BY 4.0 models from
  Sketchfab, which are no longer in the build (DECISIONS D-30). *(AI-written code)*
- `public/favicon.svg`: drawn for this project (it replaced the Vite template logo; D-16).
- All writing: story, dialogue, logs, the Ship's Library entries, LORE.md.
